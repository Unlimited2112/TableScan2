# Таблица → XLSX (Android)

Офлайн-приложение: фото таблицы (камера или галерея) → поиск сетки → OCR каждой ячейки
(Tesseract, русский язык) → редактируемый предпросмотр → сохранение / отправка `.xlsx`.

## Как получить APK без установки Android Studio (GitHub Actions)
1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки
   (можно через «Add file → Upload files», вместе с папкой `.github`).
2. Откройте вкладку **Actions** → workflow **Build APK** запустится сам (или нажмите *Run workflow*).
3. Через ~5–7 минут скачайте артефакт **TableScan-apk** → внутри `app-release.apk`.
4. Установите на телефон (разрешите установку из неизвестных источников).

## Сборка в Android Studio
Откройте папку проекта → дождитесь синхронизации Gradle → *Build → Build APK(s)*.
Модель `rus.traineddata` скачается автоматически при первой сборке (нужен интернет).

## Советы по съёмке
- Снимайте сверху, без сильной перспективы, чтобы таблица занимала почти весь кадр.
- Наклон до ±5° выравнивается автоматически.
- Объединённые ячейки определяются по отсутствию линий и сохраняются как merge в Excel.
- Числа вида `3,50` и `20%` сохраняются в XLSX как числа.
